Слитый `ref` больше не дребезжит.

У пяти компонентов, где внешний ref сливается с внутренним, колбэк задавался инлайном и
пересоздавался на каждый рендер — React честно звал старый с `null`, и наружу уезжала
череда «узел, null, узел». Для `react-hook-form` (заявленная причина, по которой ref вообще
прокинут) `ref(null)` снимает поле с учёта: оно «размонтировалось» на каждое нажатие
клавиши. Колбэк мемоизирован.

Попутно в `ds.css`: фокусная рамка поля наконец применяется (объявление проигрывало
инлайновому стилю, и переезд на токен `--focus` доехал только до React), кегль ввода на
таче больше не переопределяет чужие инпуты потребителя, сброс тонировки в
Windows High Contrast перестал проигрывать по специфичности.
