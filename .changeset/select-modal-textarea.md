Три компонента, которых не было: `Textarea`, `Select`, `Modal`.

- `Textarea` — многострочный ввод, растёт под содержимое до `maxRows`. Enter остаётся полю, отправка — Cmd/Ctrl+Enter.
- `Select` — выбор из перечня, который не помещается на экран. `value` — значение опции, а не её номер. Всплывающий список в портале: его не режет `overflow` предка. Клавиатура как у нативного селекта, включая поиск по буквам. При `name` рендерится настоящее скрытое поле — работают FormData, автозаполнение и `required`.
- `Modal` — модальное окно: фон уходит из таба и из озвучки, обход заперт, фокус возвращается на кнопку-открывашку, прокрутка страницы стоит. `dismissible: false` даёт обязательное решение с ролью `alertdialog`. Подтверждение окно само не закрывает: `confirmLoading` даёт кнопке спиннер, закрывает тот, кто знает, что действие удалось.

Новый токен `--overlay` — затемнение под окном.

Порядок слоёв всплывающего считает сам слой: список, открытый внутри окна, ложится поверх него. Клавишу закрытия съедает верхний слой — Escape в открытом списке закрывает список, а не окно.

`collapsedProps` (свёрнутые раскрывашки, подсказки, уходящий тост) чинит `inert` для React 19: пустая строка там означает ЛОЖЬ, и атрибут не попадал в DOM вовсе.

Статус всех трёх — `beta`: у них новый для системы приём (портал), и первое применение внутри прокручиваемой панели у потребителя может показать то, чего не показала витрина.
