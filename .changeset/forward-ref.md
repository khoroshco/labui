`ref` прокидывается на корень каждого компонента.

Без него потребитель добирался до узла запросом по DOM из своего кода — то есть
пользовался системой мимо контракта. Теперь `ref` приезжает на КОРЕНЬ, а не на внутренний
узел: поставить фокус, померить, привязать поповер.

Пять компонентов держат корневой ref для своих нужд (`OptionGroup` и `Tabs` меряют им
скользящую подложку, `Slider` крутит желе, `Input` перезапускает анимацию отказа,
`PinComposer` ставит автофокус) — там внешний ref не отнимает внутренний, узел получают оба.

Держит `tests/parity/ref.spec.js`: ни один другой гейт ref не видит — в DOM он не атрибут,
и ошибка «приняли, но никуда не поставили» прошла бы молча.
