# Banner Lab DS

Дизайн-система Banner Lab: 27 компонентов, токены, витрина-спека. Код рабочий, а не мокапы — открывается в браузере и соблюдает свои правила.

**Живая витрина:** https://khoroshco.github.io/labui/

Весь код здесь пишет AI, ревью человеком нет. Поэтому надёжность держится не на внимательности, а на автоматике: около 290 проверок на каждый PR, красный прогон блокирует мёрж.

## Запуск

```bash
npm ci
npm run dev
```

Витрина откроется на `http://localhost:5173/`. Нужен Node из `.nvmrc`.

```bash
npm run verify    # все гейты разом, ~2 минуты
```

## Что где лежит

```
CLAUDE.md            конституция системы — правила и инварианты, читается автоматически
CONTRIBUTING.md      порядок правок и Definition of Done
ROADMAP.md           что дальше: DTCG-токены, api.json, миграция на React
api.json             машинный источник состава: пропсы, уровни, статусы, вложенность
types.d.ts           типы пропсов для потребителей (генерируются)
components.json      рукописное: зрелость stable/beta и правила композиции
src/                 tokens.css, ds.css, хелперы, рантайм, шрифты, иконки
  atoms/             Button, Input, Checkbox, Toggle, CycleButton, OptionGroup, Badge, Skeleton, Avatar, Pin
  molecules/         RowLabel, RowInfo, RowMsg, InputRow, ChoiceRow, SwitchRow, CheckboxRow, ActionRow,
                     Slider, Disclosure, Segments, Tabs, Toast, PinCard, PinComposer
  organisms/         Island, EmptyState
storybook/           витрина — единственный источник истины по составу и правилам
packages/tokens/     @banner-lab/tokens — единственный публикуемый пакет
tests/               unit (без браузера), smoke, visual, a11y
docs/adr/            решения, которые не надо переигрывать
```

Раскладка по уровням — для читателя. Рантайм монтирует компоненты по **плоскому** пространству имён (`/Button.dc.html`, `/tokens.css`, `/svgs/*`); перевод одного в другое делают дев-сервер и сборка сайта. Почему так — [ADR 0001](docs/adr/0001-плоское-пространство-имён.md).

## Гейты

| гейт | что держит |
|---|---|
| `lint:tokens` | ни одного литерального цвета, изинга, веса, интерлиньяжа; примитивы `--c-*`/`--k-*` не напрямую |
| `lint:props` | проп объявлен ⇔ читается; колбэк без пропа-значения замораживает контрол |
| `lint:api` | `api.json` и `types.d.ts` не разошлись с исходниками |
| `lint:showcase` | витрина не показывает несуществующее и не забывает существующее |
| `test:unit` | управляемый режим шести контролов, композиция рядов, магнит слайдера, состав валидации |
| `test:smoke` | каждая страница грузится без ошибок, со шрифтом и смонтированным компонентом |
| `test:visual` | disabled, хит-зоны, оптическая центровка по ink-центру, структура + 81 снапшот в двух темах и reduced-motion |
| `test:a11y` | axe в обеих темах, pa11y-ci (WCAG2AA), бюджет контраста на токенах |

Известные отклонения не выключают гейт, а лежат в трёх ledger'ах с объяснением и измеренным значением — [ADR 0004](docs/adr/0004-ledger-вместо-выключенного-гейта.md).

## Публикация

Публикуются **только токены** — [`@banner-lab/tokens`](packages/tokens/README.md). Компоненты на текущем DC-рантайме не публикуются: у системы ноль потребителей, и публикация создала бы связанность, из-за которой миграция на React стала бы согласованным мажором во всех сервисах вместо сравнения с эталоном. Причина целиком — [ADR 0003](docs/adr/0003-не-публикуем-компоненты.md), план — `ROADMAP.md`.

## Правки

Читай `CONTRIBUTING.md`. Коротко: `CLAUDE.md` → правка в `src/` → `npm run verify` → ченджсет → PR. Никогда не редактируй `support.js` и не обновляй визуальные снапшоты, не посмотрев на диффы.
