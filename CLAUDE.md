# Banner Lab DS — как здесь работать

Дизайн-система на React. Весь код пишет AI, ревью человеком нет — поэтому надёжность держится
на автоматике, а не на внимательности.

## Три правила, которые дороже остальных

1. **Проверяемо машиной, объяснено человеком, выведено из кода везде, где это возможно.**
   Что можно вывести из кода — обязано выводиться, а не описываться: состав витрины строится
   из `api.json`, галерея иконок — из `src/svgs`, типы потребителя — из исходников. Что вывести
   нельзя — обязано иметь гейт, а гейт обязан иметь объяснение одной фразой.
2. **Гейт сначала краснеет на находке и только потом зеленеет на исправлении.** Обратный
   порядок даёт зелёный гейт над сломанным кодом; это ловили дважды за один заход.
3. **Документ обновляется тем же коммитом, что и реальность.** Разошедшийся документ — это
   не «неточность», это ложное правило, которое следующий агент исполнит буквально.

## Чего не делать никогда

- **Не редактировать `src/support.js`** — сгенерированный рантайм эталона.
- **Не править компоненты в `src/atoms|molecules|organisms` и `storybook/`** — это
  замороженный эталон (тег `ds-reference-v0`), мера паритета. Живые входы обеих реализаций
  правятся как обычно: `src/ds.css`, `src/svgs/`, `src/fonts/`, `src/ds-helpers.js`.
- **Не обновлять визуальные снапшоты, не посмотрев на диффы.** `--update-snapshots` вслепую
  превращает гейт в штамп; в CI снятые эталоны уезжают артефактом именно для просмотра.
- **Не писать литеральные цвета, изинги, веса и интерлиньяжи** — только токены.
- **Не заводить стилевые файлы и CSS-классы для компонентов.** Стили инлайновые; в `ds.css`
  живёт только то, что инлайном не выражается ([ADR 0010](docs/adr/0010-стили-инлайном-в-react.md)).
- **Не расширять состав.** Новые компоненты — решение владельца, а не следствие фазы.
- **Не «улучшать» дизайн по ходу.** Видишь проблему — заведи запись, а не правку.
- **Не глушить гейт.** Выключенный тест не оставляет следа; строка в ledger'е с объяснением
  оставляет.

## Запуск

```bash
npm ci
npm run dev       # витрина на localhost:5173
npm run verify    # все гейты разом
```

Правки идут в `packages/ds-react/src/`. Прямой пуш в `main` запрещён технически: ветка → PR →
зелёные гейты → мёрж.
