# 0007. Визуальные эталоны отдельно для macOS и Linux

**Статус:** принято · шаг 6 переезда

## Контекст

Рендер шрифта на macOS и Linux разный: та же надпись даёт 0.6px и 1.0px отклонения чернильного центра, а снимки отличаются на уровне сглаживания. Один набор эталонов означает либо красный CI, либо разрешённый порог различий такой ширины, что гейт перестаёт что-либо ловить.

## Решение

Playwright по умолчанию именует снимки с платформой (`…-chromium-darwin.png`, `…-chromium-linux.png`). Держим оба набора. Линуксовые сняты первым прогоном CI, скачаны артефактом, **просмотрены глазами** и закоммичены.

Числовые допуски (оптическая центровка) подобраны так, чтобы покрыть разницу платформ, но остаться уже потери компенсации: 1.5px против 2.5px.

## Последствия

- Разработчик на macOS и CI на Linux видят каждый свой эталон, оба честные.
- Появится третья платформа — появится третий набор; артефакт `snapshots-<OS>` для этого и уезжает из CI.
- Цена: 162 файла эталонов вместо 81 (872 КБ).
