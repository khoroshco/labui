# 0010. Стили в React — инлайновые объекты, без CSS-in-JS на рантайме

**Статус:** принято · Фаза 3

## Контекст

Правило «только инлайновые стили» происходило от потоковой отрисовки в дизайн-инструменте, а не от дизайна: классы задерживали первую отрисовку при потоковой сборке страницы. В репозитории с бандлером этой задачи нет, и правило подлежало пересмотру.

Варианты, рассмотренные при переносе: StyleX / Panda CSS (извлечение на сборке), CSS Modules, Tailwind, рантайм CSS-in-JS.

## Решение

Значения остаются инлайновыми — обычными объектами стилей React. Глобальные правила (фокус, пресс, тултипы, `forced-colors`, `reduced-motion`, кейфреймы, сепараторы острова) остаются в `ds.css`, как и были.

## Почему так, а не StyleX или Panda

- **Паритет доказуем.** Миграция проверяется сравнением с замороженным эталоном пиксель в пиксель. Инлайн — прямой перенос: тот же порядок свойств, те же значения, тот же каскад. Любой слой перевода добавляет к диффу шум, который придётся объяснять.
- **Рантайма нет и так.** Объект стилей React — это статическая структура; никакой инъекции CSS во время работы не происходит. Главный минус рантайм-CSS-in-JS (налог на каждого потребителя) отсутствует уже сейчас.
- **Нулевая зависимость.** Для библиотеки, которую ставят в чужие приложения, каждая зависимость — налог. StyleX и Panda требуют своего шага сборки у ПОТРЕБИТЕЛЯ или предсобранного CSS с фиксированными классами.
- **Значения контекстны.** Половина стилей вычисляется из пропсов (цвет по тону, отступ по размеру, оптический сдвиг по форме набора). В утилитарную шкалу это не ложится — Tailwind пришлось бы кормить произвольными значениями, теряя ровно ту точность, которой система и отличается.

## Что осталось в силе

**Ни одного литерального цвета, веса, интерлиньяжа и изинга в компоненте** — только токены. Это правило про источник значений и от способа доставки не зависит; гейт `lint:tokens` проверяет и `.tsx`.

## Последствия

- Псевдоклассы и медиазапросы инлайном не выражаются — они и остаются в `ds.css`, как было.
- Пересмотр возможен: если понадобится SSR-критический CSS или тема без CSS-переменных, решение переигрывается новой записью.
