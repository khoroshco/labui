# 0003. Публикуем только токены, компоненты — после миграции

**Статус:** пересмотрено 30.07.2026 · отменяет шаг 8 плана переезда

## Контекст

В плане переезда стояло «опубликовать 1.0.0». На момент написания это было верно, сейчас нет.

У системы ноль потребителей и ноль контрибьюторов. Это самое дешёвое окно, которое когда-либо будет, и оно закрывается в момент, когда первый сервис поставит пакет. Публикация компонентов на DC-рантайме создаёт ровно ту связанность, из-за которой миграция на React (ROADMAP, Фаза 3) стала бы согласованным мажором во всех сервисах вместо сравнения с эталоном.

## Решение

Публикуется только `@khoroshco/tokens`: он не зависит от рантайма и полезен любому стеку немедленно. Корневой пакет помечен `private: true` — случайный `npm publish` компонентов не пройдёт технически. Модель потребления и версия 1.0.0 определяются после миграции.

## Пересмотр 30.07.2026: причина исчерпана, решение меняется

Запрет держался на ОДНОЙ причине: связанность с DC-рантаймом. Миграция прошла — компоненты
уезжают на React, — и причина исчезла вместе с рантаймом в пакете. Осталась другая, не
техническая: система делается для своих сервисов, а не для всех подряд.

**Новое решение: публикуем оба пакета ПРИВАТНО, в реестр GitHub Packages.**

- Скоуп `@khoroshco` — требование реестра: имя пакета обязано совпадать с владельцем
  репозитория. Прежнее `@banner-lab` осталось в текстах как имя системы, а не пакета.
- Видимость наследуется от репозитория: он приватный, значит и пакеты приватные. Ни каталога,
  ни случайных потребителей.
- Отдельный секрет не нужен. Публикует встроенный `GITHUB_TOKEN` с правом `packages: write`;
  потребителю нужен свой токен только на чтение (`read:packages`).
- Регистрация на npmjs.com не требуется вовсе.

Чем платим: потребитель обязан положить `.npmrc` с адресом реестра и токеном — без этого
`npm i` не найдёт пакет даже при доступе к репозиторию. Это цена приватности, и она известна.

## Последствия

- Пилот-сервис и первая связанность появляются в Фазе 4 — осознанно и один раз.
- Контрдовод «без потребителя сделаете не то» принят, но отвечает на него пилот сразу после миграции: мигрировать под неизвестного потребителя дешевле, чем вместе с известным.
- Токены версионируются с первого дня, переименование токена — мажор.
