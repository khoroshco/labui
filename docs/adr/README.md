# Записи о решениях (ADR)

Здесь лежат решения, которые **не надо переигрывать**. Каждая запись объясняет, что выбрали, почему и чем за это платим. Если решение кажется странным — сначала прочитай запись: скорее всего, альтернатива уже рассмотрена и стоит дороже.

Менять решение можно, но не молча: новая запись со ссылкой на старую и статусом «заменяет 000X».

| № | Решение | Статус |
|---|---|---|
| [0001](0001-flat-namespace.md) | Плоское пространство имён URL при раскладке по уровням | принято |
| [0002](0002-resources-flag.md) | Флаг `window.__resources = {}` в каждой странице | принято |
| [0003](0003-private-publishing.md) | Публикуем только токены, компоненты — после миграции | принято |
| [0004](0004-ledger-not-disabled-gate.md) | Известные отклонения — в ledger, а не в выключенном гейте | принято |
| [0005](0005-showcase-from-api.md) | Витрина сверяется с `api.json` → **строится из него** | пересмотрено в Фазе 2 |
| [0006](0006-minimal-dependencies.md) | `node --test` вместо vitest, зависимости по счёту | принято |
| [0007](0007-two-platform-baselines.md) | Визуальные эталоны отдельно для macOS и Linux | принято |
| [0008](0008-contrast-as-is.md) | Контраст ниже AA — принятое отклонение, палитра не меняется | принято |
| [0009](0009-tokens-in-dtcg.md) | Источник токенов — DTCG, `tokens.css` становится артефактом | принято |
| [0010](0010-inline-styles.md) | Стили в React — инлайновые объекты, без CSS-in-JS на рантайме | принято |
| [0011](0011-controlled-idiom.md) | Управляемость по значению, а не по колбэку | принято |
| [0012](0012-parity-harness.md) | Миграция принимается паритетным харнессом, а не ревью | принято |
| [0013](0013-own-pixel-baseline.md) | У каждой реализации свой пиксельный эталон; общего снимка паритета нет | принято |
| [0014](0014-public-repository.md) | Репозиторий публичный; пакеты тоже — отменяет 0003 | принято |
