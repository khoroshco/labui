# Записи о решениях (ADR)

Здесь лежат решения, которые **не надо переигрывать**. Каждая запись объясняет, что выбрали, почему и чем за это платим. Если решение кажется странным — сначала прочитай запись: скорее всего, альтернатива уже рассмотрена и стоит дороже.

Менять решение можно, но не молча: новая запись со ссылкой на старую и статусом «заменяет 000X».

| № | Решение | Статус |
|---|---|---|
| [0001](0001-плоское-пространство-имён.md) | Плоское пространство имён URL при раскладке по уровням | принято |
| [0002](0002-флаг-resources.md) | Флаг `window.__resources = {}` в каждой странице | принято |
| [0003](0003-не-публикуем-компоненты.md) | Публикуем только токены, компоненты — после миграции | принято |
| [0004](0004-ledger-вместо-выключенного-гейта.md) | Известные отклонения — в ledger, а не в выключенном гейте | принято |
| [0005](0005-витрина-сверяется-с-api.md) | Витрина сверяется с `api.json`, а не строится из него | принято, пересмотр в Фазе 2 |
| [0006](0006-минимум-зависимостей.md) | `node --test` вместо vitest, зависимости по счёту | принято |
| [0007](0007-эталоны-на-две-платформы.md) | Визуальные эталоны отдельно для macOS и Linux | принято |
