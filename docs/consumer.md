# Как подключить дизайн-систему к сервису

Пакеты приватные и лежат в реестре GitHub Packages: они для своих сервисов, а не для всех
([ADR 0003](adr/0003-private-publishing.md)). Регистрация на npmjs.com не нужна.

## Установка

Рядом с `package.json` сервиса — файл `.npmrc`:

```
@khoroshco:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=${GITHUB_TOKEN}
```

Токен — классический PAT с правом `read:packages`. Держи его в переменной окружения, а не
в файле репозитория. Для CI другого репозитория: либо тот же токен секретом, либо в
настройках пакета на GitHub дать доступ этому репозиторию — тогда хватит встроенного
токена Actions.

```bash
npm i @khoroshco/ds @khoroshco/tokens
```

## Подключение

```tsx
import '@khoroshco/tokens/tokens.css';
import '@khoroshco/ds/ds.css';
```

Порядок важен: `ds.css` пользуется токенами. **Забытый `tokens.css` ничего не сломает
громко** — просто пропадут фокус-кольца на всей странице и схлопнется геометрия контролов,
потому что `var(--focus-ring)` и `var(--control-h-m)` окажутся неопределёнными.

**Гарнитуру подключает потребитель.** Unica 77 — коммерческий шрифт, пакет её бинарники не
раздаёт. Объяви `@font-face` для family «Unica 77»: Regular 100–450, Medium 451–700,
ExtraBlack 800–950. Без неё браузер возьмёт системный шрифт, а вместе с ним уедут метрики и
вся оптическая центровка — она считана по глифам Unica.

**Тема — атрибут на корне.** Базовая тёмная; светлая — `data-theme="light"` на `<html>`.

**`ds.css` трогает глобальные селекторы:** `html`, `body`, `*`, `button`, `a`,
`::placeholder` и `[aria-disabled] *`. Это осознанно — там живёт то, что инлайном не
выражается (фокус, пресс, тултипы, `forced-colors`, `prefers-reduced-motion`, кейфреймы,
сепараторы острова), — но если у сервиса есть свой глобальный ресет, порядок подключения
решает.

## Что нужно знать, чтобы не воевать с системой

**Передал значение — передай и обработчик.** Управляемый контрол показывает РОВНО то, что
пришло сверху: если есть `checked`/`value`, а обработчика нет, менять его нечем и он
замрёт. Нужно начальное значение — это `defaultChecked`/`defaultValue`. Исключения —
`Input` и `Slider`: набор и перетаскивание всегда живые, значение сверху задаёт начальное
и перекрывает своё, когда приходит новым.

**Ряды живут в острове.** `Island` собирает их из конфига `rows` и владеет углами, фоном и
сепараторами. `Slider` и `Disclosure` — вне острова, отдельной стопкой. Ряду можно дать
`key`: без него ключом служит позиция, и при сортировке состояние переезжает на соседа.

**Наружу выходят** `className`, `id`, `data-*` и `aria-*` — на корень компонента. `ref`
пока не прокидывается; если упрёшься в это (например, `react-hook-form`), скажи — добавим
осознанно, а не «на всякий случай».

**Локального визуала быть не должно.** Цвет, кегль, отступ, радиус, тень, движение — только
токенами. Это не стилистика: у системы есть гейт, который ловит литералы, и он же держит
темы и `forced-colors` работающими.

**Валидация принадлежит ряду, а не острову.** `msg` + `msgLevel` есть у `InputRow` и
`CheckboxRow`; у `SwitchRow` есть предупреждение, но не ошибка; у `ChoiceRow` валидации нет
вовсе — выбранная опция есть всегда.

## Состав

27 компонентов: атомы (`Button`, `Input`, `Checkbox`, `Toggle`, `CycleButton`,
`OptionGroup`, `Badge`, `Skeleton`, `Avatar`, `Pin`), атомы ряда (`RowLabel`, `RowInfo`,
`RowMsg`), ряды (`InputRow`, `ChoiceRow`, `SwitchRow`, `CheckboxRow`, `ActionRow`),
самостоятельные молекулы (`Slider`, `Disclosure`, `Segments`, `Tabs`, `Toast`, `PinCard`,
`PinComposer`) и организмы (`Island`, `EmptyState`). Плюс `Icon` и хуки
(`useControlled`, `useReducedMotion`, `useSpin`, `useTrackActive`, `installFocusModality`).

Живая витрина со всеми пропсами и плейграундами: https://khoroshco.github.io/labui/

## Если что-то выглядит не так

Сначала проверь три вещи: подключён ли `tokens.css`, объявлен ли `@font-face`, и не
перебивает ли глобальный ресет сервиса правила `ds.css`. Три четверти «система выглядит
сломанной» — это одно из них.

Если дело не в них — заведи запись в репозитории системы. Дизайн-система без потребителя
проверяется только гейтами, а они не знают, удобно ли ею пользоваться: это знаешь ты.
