# Репозиторий: как он устроен и почему так

Механика, без которой правки ломают систему молча. Правила самого дизайна — в
[design-system.md](design-system.md), порядок работы — в `CONTRIBUTING.md`,
решения — в [adr/](adr/).

- **React-версия — `packages/ds-react/`** (`@khoroshco/ds`): 27 компонентов, все приняты паритетным харнессом против эталона. Эталон — КОМПОНЕНТЫ в `src/atoms|molecules|organisms` плюс `storybook/`: они заморожены тегом `ds-reference-v0` и служат только для сравнения. Остальное в `src/` — живые входы ОБЕИХ реализаций и правится как обычно: `ds.css` (то, что инлайном не выражается), `svgs/` (из них собирается модуль иконок React), `fonts/`, `ds-helpers.js` (хелперы эталона) и собираемый `tokens.css`.
- Исходники эталона — в `src/`: `tokens.css`, `ds.css`, хелперы (`ds-helpers.js`, `g-icon.js`, `focus-modality.js`), рантайм `support.js`, шрифты `src/fonts/`, иконки `src/svgs/`. Компоненты разложены по уровням: `src/atoms/`, `src/molecules/`, `src/organisms/`. Витрина — `storybook/Storybook.dc.html` (+ `SbControls.dc.html`). Уровня «примитивы» среди компонентов нет: примитивы — это `tokens.css` и `ds.css`.
- **Рантайм монтирует соседей по ПЛОСКОМУ пространству имён.** `support.js` тянет вложенный компонент как `./Имя.dc.html` относительно ОТКРЫТОГО документа, а теги из `<helmet>` копируются в head того же документа — значит все относительные пути обязаны разрешаться из одной точки. Поэтому дев-сервер и сборка отдают всё плоско: `/Button.dc.html`, `/tokens.css`, `/svgs/plus.svg`, `/fonts/*.otf` (маппинг — `scripts/vite-plugin-flat-ds.mjs`). Раскладка по уровням существует для читателя, URL — для рантайма. Следствия: **имя компонента уникально во всём `src/`** (коллизия — падение дев-сервера, не тихая подмена), а в хелметах пишутся только голые имена — никаких `../` и никаких путей с уровнем.
- В хелметах **нет query-параметров**: `href="tokens.css"`, не `tokens.css?v=N`. Кэш-бастинг ручным бампом версии — механизм среды без сборки, он удалён (он же порождал двойную загрузку стилей, когда версии в разных компонентах расходились). При подозрении на устаревший кэш — жёсткая перезагрузка (Cmd+Shift+R).
- `support.js` — **сгенерированный** рантайм («GENERATED from dc-runtime/src/*.ts»). Руками не редактируется никогда. Он же тянет React 18.3.1 с unpkg по SRI — это внешняя зависимость, которую мы не контролируем (довод №2 за миграцию, ROADMAP §3.1); в тестах она перехватывается локальной копией, чтобы прогон не зависел от сети.
- **`<script>window.__resources = {};</script>` в голове каждой `.dc.html` — не убирать.** Без флага `boot()` перечитывает документ вторым запросом и пересобирает шаблон поверх уже смонтированного дерева. Второй разбор отличается от первого ТОЛЬКО регистром имён атрибутов (`onClick` → `onclick`; проверено на всех 29 страницах), а регистр рантайм нормализует сам — то есть проход не даёт ничего. При этом `RowLabel` на нём падал целиком: вместо компонента рантайм показывал заглушку «removeChild … not a child of this node». Флаг — собственная ручка рантайма, все остальные её ветки уходят в те же дефолты. Гейт следит: пропадёт флаг — smoke краснеет.
- **Неразрешённые холы шаблона в сети — известное свойство формата.** Шаблон лежит в документе настоящей разметкой, поэтому браузер успевает запросить `{{ src }}` и `svgs/{{ iconName }}.svg` до того, как рантайм подменит DOM. В компоненте это не чинится и уходит вместе с DC-рантаймом — когда витрина переедет на React. Список известных холов закрыт — `tests/smoke/known-template-holes.json`; любой новый валит smoke, потому что новый хол это либо опечатка в шаблоне, либо значение, которого больше нет.
- **Источник токенов — `tokens/banner-lab.tokens.json` (формат W3C DTCG), а `src/tokens.css` собирается из него** и лежит в `.gitignore`. Правка в CSS потеряется при первой же сборке — правь источник и запускай `npm run tokens` (он же идёт сам после `npm ci`, на старте дев-сервера и перед сборкой сайта). Трёхслойная схема в источнике сохранена один в один; часть значений — CSS-выражения, которых спецификация не описывает (альфа от канала темы, `linear()`-пружина), они помечены расширением `com.bannerlab.css` — [ADR 0009](adr/0009-tokens-in-dtcg.md). Переименование токена — мажор.
- **`api.json` — машинный источник состава, `components.json` — рукописный. Витрина строит таблицу состава ИЗ `api.json`** (`fetch('api.json')`), а не из текста: рукописный список уже расходился с кодом. Возврат рукописного массива валит гейт. Всё, что выводится из кода (пропсы, типы, дефолты, уровни, кто в кого вкладывается), генерируется в `api.json` скриптом `npm run api`; руками его не правят. `api.json` — контракт ЭТАЛОНА (`runtime: dc`); типы для потребителя отдаёт tsc в `packages/ds-react/dist/index.d.ts`, и только там есть `default*`-пропсы React. Корневого `types.d.ts` больше нет: он описывал эталон, а назывался контрактом для потребителей. В `components.json` лежит только то, чего в коде нет: зрелость stable/beta и правила композиции (что живёт вне острова, где нет валидации). Смена контракта без перегенерации — красный гейт.
- Порядок правок и Definition of Done — `CONTRIBUTING.md`. Решения, которые не надо переигрывать, — `docs/adr/`: там записано, чем платим за каждое, поэтому спор начинается с чтения записи, а не с правки.
- **Каждая страница системы — документ**: `<html lang="ru">` и непустой `<title>`. Без них любая `.dc.html` валит pa11y на 3.1.1 и 2.4.2, а витрина ещё и открывается в браузере без имени.
