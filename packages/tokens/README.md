# @banner-lab/tokens

Дизайн-токены Banner Lab: цвет, типографика, отступы, радиусы, тени, движение. Пакет не зависит от рантайма и подключается в любом стеке.

```bash
npm i @banner-lab/tokens
```

## CSS

```css
@import '@banner-lab/tokens/tokens.css';
```

Тема переключается атрибутом на корне: базовая — тёмная, светлая — `data-theme="light"`.

## JS/TS

```ts
import { TOKENS, token } from '@banner-lab/tokens';

token('--text-primary');          // 'var(--text-primary)' — типизировано, опечатка не пройдёт
TOKENS['--text-secondary'].layer; // 'alias'
TOKENS['--c-gray-900'].layer;     // 'primitive'
```

## Три слоя

1. **Примитивы** (`--c-*`, `--k-*`) — сырая палитра, «какой это цвет». В компоненты напрямую не попадают.
2. **Алиасы** (`--bg-*`, `--text-*`, `--accent`, …) — семантика, «для чего цвет». Единственный слой, который используют компоненты.
3. **Тема** (`[data-theme]`) — перемапливает алиасы на другие примитивы. Имя алиаса стабильно, меняется значение.

Полупрозрачные токены выведены из двух «чернильных» каналов (`--ink`, `--tint`), поэтому светлая тема переопределяет два токена, а не двенадцать.

## Откуда берётся

Источник — `tokens/banner-lab.tokens.json` в формате W3C DTCG: слои, ссылки, описания и типы. `tokens.css`, `tokens.json` и типы собираются из него одним скриптом. Значения, которых спецификация не описывает (альфа от канала темы, `linear()`-пружина), помечены расширением `com.bannerlab.css` — подробности в ADR 0009 репозитория.

Переименование токена — мажор: имя ушло к потребителю вместе с пакетом.
