# @khoroshco/ds

## 0.1.0

### Minor Changes

- 6cff7fd: Пакеты переименованы в скоуп `@khoroshco` и публикуются приватно в реестр GitHub Packages. Скоуп — требование реестра: имя пакета обязано совпадать с владельцем репозитория; имя «Banner Lab» осталось за системой, а не за пакетом. Видимость наследуется от репозитория, поэтому пакеты приватные и в публичном каталоге не появляются.

  Компоненты (`@khoroshco/ds`) теперь тоже публикуются: запрет держался на связанности с DC-рантаймом, а она исчезла вместе с миграцией на React — [ADR 0003](../docs/adr/0003-не-публикуем-компоненты.md) пересмотрен.

  Потребителю нужен `.npmrc` с адресом реестра и токен GitHub с правом `read:packages`. Публикации секрет не нужен вовсе: её делает встроенный `GITHUB_TOKEN`.

- b0ca25b: Фаза 3: все 27 компонентов перенесены на React и приняты паритетным харнессом — каждый воспроизводит замороженный эталон `ds-reference-v0` пиксель в пиксель в обеих темах. Идиома управления переведена на React-схему (значение, а не колбэк).

### Patch Changes

- 421d10d: Правки по консилиуму критиков.

  **Ряды острова, заданные конфигом без колбэка, больше не мертвы.** В React признак управляемости — значение, а остров отдавал вниз `checked`/`value` безусловно: тоггл, чекбокс и сегменты показывали ровно переданное, а менять их было нечем — ряд подсвечивался, продавливался, озвучивал `role="switch"` и не переключался. Теперь значение уходит вниз только вместе с колбэком, иначе — как начальное. Циклер единиц вернулся к общей идиоме всех шести контролов.

  **`Button` получил проп `type` со значением `button` по умолчанию** — без него браузерный дефолт `submit` отправлял форму потребителя, и переопределить это было нечем.

  **Мягкий бейдж тона `info` рисовался без подложки:** токен `--info-dim` использовался, но не был объявлен нигде.

  **В шипаемый `ds.css` больше не уезжают правила витрины** — в том числе `main section`, из-за которого секции у любого потребителя с `<main><section>` въезжали с задержкой.

  **Насечки магнита слайдера** показывались `opacity:0` всегда (селектор искал потомка у элемента-соседа), а клавиатурное фокус-кольцо слайдера срезалось `overflow` — оба чинятся в `ds.css`.

- 421d10d: Оснастка гейтов дожидается, пока дерево смонтируется полностью. Рантайм эталона тянет каждый вложенный компонент и каждую иконку отдельным запросом, поэтому на медленной машине проверки смотрели половину дерева: измерено, что при задержке ответов в 200 мс у острова 12 узлов вместо 119. Снимок это переживал, а сверка разметки и axe — нет: axe на половине дерева честно сообщает ноль нарушений.
- 583676f: Фаза 4: пакет компонентов собирается (`@khoroshco/ds`) — чистый ESM и типы через tsc, без бандлера. Публикация ждёт токен npm.
- 9908a36: Фаза 3: заморожен эталон (тег `ds-reference-v0`) и поднят паритетный харнесс — React-версия компонента сверяется с теми же файлами эталонов, что сняты с DC-версии. Мигрированы первые восемь атомов.
- 4a0e9e9: Гейты больше не запирают собственный релиз. Версия пакета перестала попадать в `api.json`: снапшот описывает СОСТАВ, а от номера версии не зависит ничем — зато устаревал от каждого бампа, и релизный PR (его пишет бот, он не запускает `npm run api`) не мог позеленеть никогда. Гейт ченджсета перестал требовать запись от релизного PR: тот записи тратит, а не заводит.
- ecca531: Исправления по ревью.

  **Живые контролы.** `Input`, `InputRow`, `Island`, `Slider` и `CycleButton` снова работают, когда значение приходит сверху: строгая управляемость делала поле мёртвым, если проп пришёл без колбэка. `Button` не теряет `data-tone`, лоадер соблюдает минимальную видимость, пакет сам ставит модальность фокуса (без неё у потребителя не было ни одного фокус-кольца), `Avatar` не выдумывает имя, подчёркивание вкладок перемеряется после смены подписей, `Toast` закрывается по `pointercancel`, неизвестное имя иконки не роняет рендер.

  **Пакет грузится в Node.** Собранный `dist` содержал импорты без расширений — Vite их терпел, Node нет, и пакет не импортировался вовсе. Сборка переведена на правила Node и в конце ИМПОРТИРУЕТ результат, сверяя состав экспортов.

  **`ds.css` больше не ссылается на шрифты, которых нет в пакете.** Unica 77 — коммерческая гарнитура, её бинарники пакет не раздаёт: `@font-face` объявляет потребитель (family «Unica 77»: Regular 100–450, Medium 451–700, ExtraBlack 800–950). Раньше потребитель молча получал системный шрифт, а вместе с ним другие метрики и уехавшую оптическую центровку. Sourcemap'ы теперь ведут внутрь пакета.

- a8b66c7: Слайдер: роль виджета вынесена на отдельный слой — у `role="slider"` не может быть фокусируемых потомков, а в ряду их двое (поле значения и циклер единиц). Поведение и вид не меняются, кольцо фокуса рисуется inset по той же геометрии.
