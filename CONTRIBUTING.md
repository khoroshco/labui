# Как вносить изменения

Этот файл написан для AI-контрибьютора: весь код здесь пишет AI, ревью человеком нет. Значит правило, не подкреплённое гейтом, не существует — а гейт без объяснения будет обойдён при первом же неудобстве. Поэтому здесь и то, и другое.

## Порядок

1. **Прочитай `CLAUDE.md`.** Это конституция: правила дизайна и инварианты, каждый из которых оплачен уже найденным дефектом.
2. **Ветка на задачу.** Прямой пуш в `main` запрещён технически.
3. **Меняй в `src/`.** `support.js` не редактируется никогда — это сгенерированный рантайм.
4. **`npm run verify` локально.** Все гейты разом, ~2 минуты. Красный гейт — красный PR.
5. **Ченджсет**, если менялся контракт: `npx changeset`. Без записи прогон падает.
6. **PR.** Шаблон открывается сам, чек-лист в нём — не формальность.

```bash
npm ci
npm run dev       # витрина на localhost:5173
npm run verify    # линтеры + unit + smoke + визуальные + доступность
```

## Definition of Done

Изменение готово, когда:

- [ ] `npm run verify` зелёный локально и в CI;
- [ ] правка `packages/ds-react/src/`, `src/`, `tokens/`, `api.json` или `components.json` сопровождается ченджсетом;
- [ ] `npm run api` перегенерировал снапшот контракта, если менялись пропсы;
- [ ] визуальные снапшоты обновлены **после просмотра диффов** — дифф приложен к PR;
- [ ] `CLAUDE.md` обновлён **тем же коммитом**, если правка меняет правило;
- [ ] новый компонент: smoke + unit + a11y + визуальные снапшоты + строка в `components.json`;
- [ ] новая строка в ledger'е объяснена: почему это решение, а не недоделка.

## Чего не делать

- **Не редактировать `support.js`.** Сгенерированный рантайм; правка исчезнет при следующей выгрузке и утащит с собой отладку.
- **Не обновлять визуальные снапшоты не глядя.** `--update-snapshots` без просмотра диффа превращает гейт в штамп. В CI снятые эталоны уезжают артефактом именно для того, чтобы их можно было посмотреть.
- **Не писать литеральные цвета, изинги, веса и интерлиньяжи.** Только токены. Это правило переживёт и миграцию на React: оно про источник значений, а не про способ доставки стилей.
- **Не заводить стилевые файлы и CSS-классы для компонентов** до Фазы 3. Пока формат DC, стили инлайновые; в `ds.css` живёт только то, что инлайном не выражается.
- **Не расширять состав.** Новые компоненты (Dialog, Select, Table) не нужны до конца миграции: компонент, написанный на старом рантайме, придётся мигрировать дважды, а написанный на новом — не с чем сравнить.
- **Не «улучшать» дизайн по ходу.** Почти каждое спорное решение уже обсуждено, причины — в `CLAUDE.md` и `docs/adr/`. Видишь проблему — заведи запись, а не правку.
- **Не глушить гейт.** Выключенный тест не оставляет следа; строка в ledger'е с объяснением — оставляет.

## Гейты и что они держат

| команда | что проверяет |
|---|---|
| `npm run lint:tokens` | ни одного литерального цвета, изинга, веса, интерлиньяжа; примитивы `--c-*`/`--k-*` не напрямую |
| `npm run lint:props` | проп объявлен ⇔ читается; колбэк без пропа-значения замораживает контрол |
| `npm run lint:api` | `api.json` не разошёлся с исходниками эталона |
| `npm run lint:showcase` | витрина не показывает несуществующее и не забывает существующее |
| `npm run test:unit` | управляемый режим шести контролов, композиция рядов, магнит слайдера, состав валидации |
| `npm run test:smoke` | каждая страница грузится без ошибок, со шрифтом и смонтированным компонентом |
| `npm run test:visual` | disabled, хит-зоны, оптическая центровка, структура + снапшоты в двух темах и reduced-motion |
| `npm run test:a11y` | axe в обеих темах, pa11y-ci (WCAG2AA), бюджет контраста на токенах |

## Три ledger'а

`tests/smoke/known-template-holes.json`, `tests/a11y/known-violations.json`, `tests/a11y/contrast-budget.json`.

Это не свалка отложенного, а список решений, которые принимает человек. Гейт красный **и** на новом отклонении, **и** на записи, которая перестала воспроизводиться: устаревшая строка хуже отсутствующей — отсутствующая заметна, устаревшая выглядит как истина.

## Как добавить компонент

Короткий ответ: сейчас — никак, состав заморожен до конца миграции (см. выше). Когда откроется:

1. `src/<уровень>/Name.dc.html` — имя уникально во всём `src/` (рантайм различает компоненты только по имени).
2. Секция в витрине с плейграундом, где показаны **все** пропсы.
3. Строка в `components.json` со статусом `beta`.
4. `npm run api` — снапшот контракта.
5. Тесты: smoke подхватит сам, дальше — unit на логику, визуальные снапшоты, a11y.
6. Ченджсет.
